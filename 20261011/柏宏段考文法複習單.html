Part 1 · CH13 代名詞

強調句、虛主詞、that / those、one / another / the other

① 強調句 It is/was ＿＿ that …

It was [被強調的部分] that + 剩下的句子
檢驗法：把 It was 和 that 遮掉，剩下的要是一個完整、正確的句子。
經典錯誤　It was the rain that the game was cancelled. → 遮掉後變 “The rain the game was cancelled.” 不通！要補 because of。

② It is + adj. + for / of + 人 + to V

for：形容「這件事」（easy, hard, important, necessary, dangerous）
of：形容「這個人」（kind, nice, foolish, brave, careless, rude）
小技巧：能說「人 is kind」就用 of；說「人 is easy」很怪就用 for。

③ 比較時用 that / those 代替重複的名詞

單數 / 不可數 → that　複數 → those　（不能用 this / these）

④ one / another / the other / the others

總數寫法
2 個one … the other
3 個one … another … the other
很多，只講兩種some … others
一群人分兩邊some … the others（剩下全部）
兩者：both / either / neither　　三者以上：all / any / none
也常錯　concentrate / relax / feel 後面不加反身代名詞；Every 不能當代名詞（Every of us → Each of us）；ourselves 不要拼成 ourself。

Part 2 · CH14 倒裝句

一條規則打天下：把 be / 助動詞搬到主詞前面

萬用規則（跟 so / neither 一樣）

原句有 be 動詞 → 搬 be　｜　有 助動詞（can, will）→ 搬助動詞
有 完成式 → 搬 have/has/had　｜　一般動詞 → 補 do / does / did，後面動詞變原形
類型句型例
地方副詞放句首地方 + V + S（主詞是代名詞不倒裝）On the desk is my phone.
否定副詞放句首Never / Rarely / Seldom / Little / By no means + 助 + SNever have I seen it.
Only + 副詞片語/子句Only by/when … + 助 + S + VOnly then did I understand.
Not untilNot until … + 助 + S + VNot until ten did he leave.
No soonerNo sooner had S p.p. than S V-edNo sooner had I sat down than …
Not onlyNot only + 助 + S …, but S also …Not only is she smart, but …
假設語氣去掉 if，把 were / had / should 搬前面Had I known, …
讓步adj./adv./N(無冠詞) + as/though + S + VTired as he was, …
so / suchSo + adj. + be + S + that … ／ Such + be + S + that …So tired was he that …
補語放句首adj. + be + SHappy are those who …
三大陷阱　① Next to the school has is a park.（地方倒裝不是「有」）② 倒裝後動詞跟著後面的主詞變單複數：Under the bed are two cats.　③ 讓步倒裝不能用 although，名詞放前面要去冠詞：Child as she is …

Part 3 · CH15 句型大補帖

省略 should、感歎句、附加問句、雙重否定

① 省略 should：後面一律接原形動詞

S + insist/suggest/demand/require/order … + that + S + (should) + VR
It is important/necessary/essential/urgent … + that + S + (should) + VR
… lest + S + (should) + VR（以免）
雙重身分　suggest 當「顯示」、insist 當「堅稱」時，後面正常變化動詞，不用 should。
The study suggests that sleep is important.／He insisted that he was innocent.
不能寫 suggest/insist/demand sb. to V。

② 感歎句

How + adj./adv. (+ S + V)!　→ 後面沒有名詞
What + (a/an) + (adj.) + N (+ S + V)!　→ 後面有名詞
How 後接形容詞還是副詞？看後面的動詞：be / look / sound → 形容詞；sing / run → 副詞。

③ 附加問句：前肯後否、前否後肯

前句附加問句
has p.p.（完成式）／had betterhasn't … ／ hadn't …
have to V／have + N（一般動詞）don't … ／ doesn't … ／ didn't …
used to Vdidn't …
I am …aren't I? ／ am I not?
There is/are …isn't there? ／ aren't there?
V-ing / To V 當主詞… it?
祈使句（Close …, Don't …）will you?
Let's …shall we?
含 seldom / rarely / few / little / never視為否定 → 用肯定

④ 雙重否定

否定詞 … without + N / V-ing　= 每次…都會…（強調）
not + un-/in-/im-/ir- + adj.　= 語氣委婉的肯定（not uncommon = 還蠻常見的）
